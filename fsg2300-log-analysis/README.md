# FSG2300 Log Analysis Web

FSG2300 Log Analysis Web 是 FSG-2300 製程 Log 的網頁版分析工具，可直接在瀏覽器載入批次資料夾或單片 CSV / INI 檔案，產生移除量、負載、加工時間、平均磨耗率、成品厚度、單片分析與 S1 peak 檢查圖表。

目前版本：v1.9.2

## 使用方式

1. 開啟網頁：
   <https://kevinchen660701-ship-it.github.io/PlateProfileTool/fsg2300-log-analysis/>
2. 按「批次分析」選擇資料夾。
3. 系統會搜尋資料夾內的 `Wxxxx.csv` 或 `Wxxxx.ini` 檔案並載入。
4. 使用上方頁籤切換各分析畫面。
5. 需要單片資料時，按「單片 Wafer」後直接選擇單一 CSV / INI 檔案。
6. 需要報告時，按「產出 PPT」輸出 `.pptx`。

## 主要功能

- 加工參數摘要
- G1 / G2 移除量
- 抬針後移除量
- 負載狀況
- 負載分布
- 負載時序串聯
- 負載時序並聯
- 加工時間與等待時間
- 平均磨耗率
- 成品厚度
- 單片 Wafer 分析
- S1 peak 檢查
- AI 優化建議
- PPTX 報告輸出

## S1 Peak 檢查

按「S1 peak檢查」後選擇資料夾，系統會搜尋資料夾與子資料夾內的 INI / CSV 檔案，分析 G1 / G2 的 S1 Loading 變化。

檢查結果會列出：

- 所在資料夾
- 檔案
- Wafer
- 站別 G1 / G2
- Chuck
- 結果
- 秒數
- S1 Peak
- 基準
- 差異
- 斜率
- 判定

目前判定包含：

- 急升：與前一有效點比較，S1 Loading 突然上升超過設定值。
- 整段拉升斜率：先平滑化，再從負載準備開始拉升的位置起算，檢查整段上升斜率是否超過設定值。

詳細邏輯請參考 [S1_peak檢查說明.md](./S1_peak檢查說明.md)。

## PPT 輸出

批次分析與 S1 peak 檢查皆可輸出 `.pptx`。

S1 peak 檢查的 PPT 會包含：

- 封面摘要
- 異常清單表格
- 每筆異常對應的 S1 Loading 圖
- 斜率異常的 start / end 標註、紅色虛線與箭頭

## AI 優化建議

AI 服務選項與 API Key 可儲存在瀏覽器本機端。

注意：

- API Key 使用瀏覽器 `localStorage` 儲存。
- 資料只存在目前電腦與目前瀏覽器。
- 若清除瀏覽器資料，API Key 也會消失。

## 資料隱私

此工具主要在瀏覽器本機端解析檔案。批次資料與單片資料不會因為載入分析而自動上傳。

只有使用「產生 AI 建議」時，摘要內容會送到所選 AI 服務。
